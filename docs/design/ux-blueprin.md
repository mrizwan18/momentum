# UX Principle

A user should never wonder: - Where am I? - What should I do next? -
What happens after this?

Every screen answers those questions.

# Screen Transition Rules

Dashboard ↓ Practice

Practice ↓ Recording

Recording ↓ Reflection

Reflection ↓ Summary

Summary ↓ Dashboard

No transition should exceed 300 ms.

---

# Layout Rules

Mobile-first. Maximum content width on desktop. Sticky primary action
where appropriate. Bottom navigation always reachable with one hand.

---

# Validation Checklist

✓ One primary CTA per screen. ✓ No dead-end screens. ✓ Navigation within
two taps. ✓ Calm visual rhythm. ✓ Practice always feels like the center
of the product.
